# Tessera — site

Privacy policy and terms of use for the iOS game **Tessera**
(bundle id `com.strathmorenewsplus.tessera`), published by Strathmore News Plus Ltd
via GitHub Pages.

The app links the policy from its Settings screen and follows the language the
system picked for the game, as App Store Review Guideline 5.1.1(i) requires.
Russian sits on the bare URLs; English is served alongside it.

| Document | Русский | English |
| --- | --- | --- |
| Privacy Policy | [privacy.html](https://estreshnev.github.io/tessera-site/privacy.html) | [privacy-en.html](https://estreshnev.github.io/tessera-site/privacy-en.html) |
| Terms of Use | [terms.html](https://estreshnev.github.io/tessera-site/terms.html) | [terms-en.html](https://estreshnev.github.io/tessera-site/terms-en.html) |

Set the privacy policy URL per listing localization in App Store Connect.
